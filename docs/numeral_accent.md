# 数詞アクセント規則 (Numeral Accent Rules)

数詞＋助数詞のアクセントは **テーブル駆動** です。実装は
`pitch_accent/numeral.py`、データは `data/numeral_accent.json`。

## なぜテーブルか

1〜10 の核となる組み合わせは語彙的で、音韻規則からは予測できません
（三人[3] vs 三年[0]、一回[3] vs 一階[0] — 同音でもアクセントが違う）。
このため 1〜10 × 助数詞はデータで持ちます。

## データの出所

`data/numeral_accent.json` は **日本語教育用アクセント辞典**
(accent.u-biq.org, counter1〜4) から抽出した 63 助数詞 × 数詞 1〜10
（約630セル）です。抽出スクリプトは `scripts/build_numeral_table.py`
（サイト停止時は Wayback Machine から取得）。ページの声調マークアップ
（span class a1〜a4）をアクセント核位置にデコードしています。

各エントリは `confidence` を持ちます:
- `verified` — 辞典サイト由来
- `drafted` — 手作業の下書き（NHKアクセント辞典で要確認; 現在は無し）

読み（いっぽん、さんぼん、ついたち等の音便・連濁込み）もテーブルが
提供します。

## 11以上：合成規則

11 以上の数は **最終要素の型** に従います:

```
37分 = さんじゅう + ななふん[2]  → さんじゅうななふん[6]  （オフセット+2）
30分 = さん + じゅっぷん[1]      → さんじゅっぷん[3]
2024年 = にせんにじゅう + よねん[0] → 平板のまま [0]
24日 = にじゅう + よっか[0]      → にじゅうよっか[0]
```

最終要素のセルが平板ならば全体も平板。核があればプレフィックスの
モーラ数だけ右にずれます。

**補充形（suppletive）は合成不可**: ひとり・ふたり・ついたち・ふつか・
とおか等は 11 以上に合成されません（12日は じゅうににち であって
じゅうふつか ではない）。`COMPOSABLE_PREFIXES` が生産的な音便形
（いっ・ろっ・はっ・じゅっ・よ等）だけを合成対象として許可します。
合成できない場合は None を返し、パーサーは複合名詞規則にフォールバック
します。

## 助数詞の検出（パーサー側）

UniDic の助数詞タグ付けは不統一です:

| 例 | UniDic 品詞 |
|----|-------------|
| 本 | 接尾辞/名詞的/助数詞 |
| 冊・人 | 接尾辞/名詞的/一般 |
| 年・分・階 | 名詞/普通名詞/助数詞可能 |

`SentenceParser._is_counter` はこれらすべてを助数詞として扱います
（数詞を含む名詞連続の中でのみ判定）。

## 優先順位

1. **辞書** (Kanjium) — 一人[2] 等、表層＋読みが一致すれば最優先
2. **数詞テーブル** — 上記
3. **複合名詞規則** — テーブル外の助数詞（円 等）のフォールバック

## テスト

`tests/test_numeral.py` — テーブル値・合成規則・パーサー経路の回帰テスト。

## 既知の制限

- **円・週(単独)・か所 など** はテーブル未収録（複合名詞規則へ
  フォールバック）。`DRAFTED` に confidence=drafted で追加可能。
- 100 の倍数（100分等）はアンカーが無いためフォールバック。
- 「三日目」のような 助数詞＋接尾辞 連鎖は助数詞部分のみ計算。
